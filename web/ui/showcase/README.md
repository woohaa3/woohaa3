# Component Lab

本目录是 `@woohaa3/ui` 包内的**独立 workspace 包** `@woohaa3/ui-showcase`：依赖方向仍是 showcase → ui/frontend/extensions，UI 生产入口不依赖它。Ladle 同时发现 `../src/**/*.stories.*` 的共享组件与 `src/**/*.stories.*` 的生产业务组合。在本目录执行 `pnpm typecheck`、`pnpm test`、`pnpm build`（或在仓库根执行 `pnpm -C client/web/ui/showcase ...`）；已有 story ID 保留，排序与自有侧栏共用 `src/shell/story-order.mjs`。

组件目录覆盖基础控件、表单、图标/Logo、设置反馈、Dialog/portal、媒体、助手、复制和主题桥。通过控件切换 disabled/loading/空内容、长名称和错误；操作结果回流到受控值或下方 recorder。复制示例支持 false/reject/迟到结果，媒体支持换源/卸载，确认框首次失败后可重试。

“业务集成”直接挂载生产组件，内存 adapter 由 `src/integration` 提供：

| 示例 | 可操作场景 |
| --- | --- |
| 设置与插件 | 修改、保存、失败重试、保持/结算保存、locked、秘密清理、dirty 退出保护 |
| 插件安装 | 搜索、版本、信任、提交安装、失败重试、推进安装任务 |
| 能力中心与 MCP | ready/loading/empty/error 目录、重新检测、安装失败后点击重试 |
| 扩展配置 | SDK/本地助手保存与删除、检测失败、保持请求、凭据清理、内存 OAuth 授权结算、远端登录与退出 |
| 监控与遥测 | 查询、筛选、详情、空/错误/恢复、更新快照、加载更多 |
| 聚焦与反馈 | 目标失效与恢复、媒体状态、返回保护、安全模式重启失败/重试、连接恢复、局部异常、长错误与任务状态 |

“内存场景”切换数据源；“完成内存请求”结算挂起请求。所有写入、授权和安装只影响该示例的内存，不访问真实设置、凭据、客户端文件、任务库或遥测库。生产查询、导航和业务状态仍由原组件/控制器持有。测试检查生产组件挂载、失败恢复和禁止外部网络。

既有执行、历史、片场、视频、片段库和活动故事继续使用原生产流程。默认/暗色/sentinel 由壳层主题桥提供。电脑/Pad 验收尺寸为 1440×1000 和 1024×768；真实应用渲染和视觉检查须在真实 GPU 上执行，Ladle 构建与 DOM 测试不替代这些证据。

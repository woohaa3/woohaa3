# soma-body-v1

These twenty-one bodies were generated offline with NVIDIA SOMA-X 0.3.6
(commit `01ab5b5c0876058bd27d34b1607d74b2e55e0cf4`) and NAVER Anny 0.2.0.
The source SOMA-X model and code use Apache-2.0. Anny code is copyright
2025 NAVER Corp., Apache-2.0; the Anny MPFB2/MakeHuman body assets are CC0-1.0.
See the accompanying licenses and upstream attributions. No optional
noncommercial SMPL-X topology or separately licensed SMPL/MANO asset is used.

Modified/generated by Woohaa: Anny age, sex and weight controls, a local waist
control for fat bodies, adult body-segment proportion calibration (legs and
torso, with the visible head geometry kept intact), visible-head calibration
from Head/Jaw skin influence, torso/limb-specific body-width compensation,
SOMA-X skeleton fitting and T-pose
rebinding, normalization to 1.70 m for adults or .70 / 1.15 / 1.50 m for baby / child / teen with soles at
Y=0, and lossless float32/uint32 packing. All ten exported skin influences
are retained. Every preset's parameters, measurements, source asset digests,
and geometry/skeleton digests are in manifest.json. The content hash covers
vertices, world binds, inverse binds, faces, indices and weights in that order,
using little-endian float32 and uint32.

Head height uses the external SOMA mid-topology chin vertex 16 and the maximum
Y of the visible skinned head marker. The marker contains vertices with at
least 50% combined `Head`/`Jaw` skin influence, so rendered hair and face
surfaces are included. This is a frozen surface landmark, not Head/HeadEnd
bone length; the exact vertex list and rule are in manifest.json.
Girths follow closed horizontal surface contours nearest the midsagittal plane;
the generator documents the skeleton-relative section heights.

Runtime data lives in contracts/src/canvas/soma-humanoid/body-{data,manifest}.ts.
It is embedded in the client build; creating a body needs no Python or download.
Regenerate using scripts/soma-body-presets/generate.py and its locked environment.
The complete catalog must pass before output files are published. This identity
must not be overwritten by later geometry; use a new catalog version instead.

The five age presets retain Anny age-dependent proportions without adult
body-segment head-ratio calibration. Adult ratios lengthen or shorten the legs
and torso while keeping the visible head geometry intact. Age parameters: baby=0 (neutral gender=.5), child=1/3,
teen=.5; gender-specific child/teen anchors use male=0, female=1.
The catalog is append-only: previously published entries and shared metadata
must remain byte-for-byte equivalent; new age entries do not replace adults.

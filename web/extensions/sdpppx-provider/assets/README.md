# sdpppx-provider 品牌图形

`icon.svg` 是设置页插件卡片与供应商入口用的第三方品牌图形，随扩展包发布。

来源：<https://raw.githubusercontent.com/zombieyang/sd-ppp/refs/heads/main/static/sdppp-icon.svg>（2026-11-09 取得）。

- 用途：SDPPPX Provider 在设置页与 AI 助手供应商列表中的图标。
- 处理：文件按字节原样复制，未做修改。
- 归属：sdpppx / SD-PPP 名称及图形归其权利人所有。

新增或更换图形时：保持文件名 `icon.svg`，更新本文件的来源说明，并在 `extension.json` 的 `icon.asset` 里指向它；宿主目录里的副本由 `pnpm -C web run icons:sync` 生成。

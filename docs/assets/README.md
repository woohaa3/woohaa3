# README 品牌素材

`woohaa3-banner.png` 是项目首页使用的透明底 banner，尺寸为 1536×512。图形与英文字标来自 WooHaa3 品牌主稿；中文副标题为「无限画布3D版」。

副标题使用 **ZCOOL QingKe HuangYou（站酷庆科黄油体）Regular**，颜色为 `#b8d1c7`。英文按 `Woo`、`Haa`、`3` 三组排布，组间可见间距约 52px；按实际字形轮廓排版，跟随英文字标上扬方向。「无」「画」「3」的视觉中心分别对应上方 W、H、3；「限」「布」以 40px 字号排版，约为其余 58px 字符的 69%。

字体来自 [Google Fonts 的 ZCOOL QingKe HuangYou](https://github.com/google/fonts/tree/main/ofl/zcoolqingkehuangyou)，项目作者与来源见[字体项目](https://github.com/googlefonts/zcool-qingke-huangyou)。字体采用 [SIL Open Font License 1.1](licenses/ZCOOLQingKeHuangYou-OFL.txt)，允许商用、嵌入与制作图片；本仓只分发排版后的 PNG，不分发字体文件。字体许可不改变 WooHaa3 原创代码的 MIT 许可。

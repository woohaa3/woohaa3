# 快速入门截图

这些截图用于客户端 README 的使用指引，摄于 2026-11-07 的 dev 服务，通过 CDP 连接 Windows 上的 Microsoft Edge，使用 NVIDIA GeForce RTX 4060 硬件渲染。

采集基线：client `5cc13bb260b69ca7aea9e73ab1816e32036e2793`，含工作区中的开发改动；界面可能与已发布版本略有差异。

素材来自已有房间演示画布及已完成的生成结果。本次仅打开真实界面、添加后移除组合参考草稿、调整后放弃镜头草稿，没有提交新的模型生成或恢复历史版本。运行时控制器仅用于定位节点与调整画布视野。

- `01-ai-center.webp`：AI 能力中心总览。
- `02-generate-image.webp`：图片节点及生成面板。
- `03-convert-3d.webp`：生成模型与导演区对话框。
- `03-original-view.webp`：床、沙发与窗户的原图全景。
- `03-camera.webp`：同一房间的衣柜近景镜头编辑界面。
- `04-new-angle-result.webp`：衣柜近景镜头对应的已完成成图。
- `05-version-history.webp`：图片节点版本面板。

视角配图复用同一房间的两组已有镜头与成图：全景成图对应 `asset-camera-node-157dewg`，衣柜近景成图对应 `asset-camera-node-mthwfk`。近景成图的已有生成记录以该镜头为参考，未包含全景图片输入；配图用于展示视角与成图的对应关系，不代表本次重新执行了组合参考生成。

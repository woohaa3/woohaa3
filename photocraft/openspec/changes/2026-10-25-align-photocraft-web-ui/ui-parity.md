# Web / 原生 UI 对齐记录

基线：固定 vendor revision 的 `crates/ui-egui/src/{menus.rs,menu_catalog.rs,panels.rs,dock.rs,brush_sections.rs}`。范围为 Web 已接入能力的入口、层级、密度和交互；文档工作区、顶部窗口标题栏及画布渲染不在此次重做范围。嵌入中间区域直接透出宿主画布。

## 笔刷及真实运行修复

- 删除笔迹参数中的固定 spacing，使用 native BrushSettings；保留子像素坐标、压力、倾角、旋转和时间戳，补齐 coalesced/抬笔采样。
- `strokeWantsTime()` 只读桥接 native generator；喷枪与滞后平滑需要时间时才继续调度同位置样本，结束/取消后停止，整笔仍只提交一步。
- 应用预设通过 `tools.setBrush({preset})` 真正加载；`brush.presets.setCurrent` 只标记身份，不再被当作应用动作。加载后回填 Web 参数；保存/更新前同步本地参数。平滑保留当前工具值，遵循 native preset picking 语义。
- 命令响应在 WASM 边界解码 JSON，修复预设等面板收到字符串而拒绝列表。
- 补齐合成剪贴命令必需元数据，防止一条畸形记录使整张命令表失效。保留无 menu 路径的 allowed 命令供面板能力投影，菜单仍按显式目录生成。
- 亮度/曲线直接调整补严格 native 参数校验，与现有像素算法、撤销和资源门禁共用执行路径。
- 工具记忆保留成员身份，返回选框时保留变体；按住工具快捷键的临时切换在原生工具组路由中恢复。命令搜索的变体使用独立标识，避免 React 重复键导致错误工具残留；精确名称优先，按菜单路径搜索子菜单命令。
- 独立宿主和主应用的运行时 ID 在普通 HTTP 下兼容 `crypto.randomUUID` 缺失：优先原生 UUID，否则使用 `crypto.getRandomValues` 的 UUID v4 回退。

## 能力边界与外部验收

原生完整通道/路径/动作库、资源库管理、跨组单 Tab 拖动与任意拆分 dock、未开放工具/动态编辑字段均不在 Web 现有能力集合内；不为这些能力添加可执行空壳。已有预设仍可携带 native 动态设置。此次没有修改 vendor、generated 协议绑定或工程格式。

已做浏览器布局/实际操作和模拟笔设备输入检查；当前 Chromium 使用 SwiftShader，Linux 无 `/dev/dri/renderD*`。这些结果不能证明真实 GPU 性能或实体数位笔手感，后者需要硬件环境验收。
